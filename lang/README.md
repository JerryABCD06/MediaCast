# 语言文件

这个目录里一个 `.json` 就是一种语言。程序**启动时扫一遍**，扫到什么，设置页的
语言列表里就有什么 —— 加一种语言不用改代码、不用重新编译。

## 文件长什么样

```json
{
  "meta": {
    "name": "简体中文",
    "system": ["zh_CN", "zh_Hans_CN", "zh_SG", "zh_Hans_SG"]
  },

  "strings": {
    "tray_open_main": "打开主界面",
    "ui_settings_language_system": "跟随系统"
  }
}
```

`meta` 只有两项，都是给程序用的：

| 字段 | 干什么的 |
|---|---|
| `name` | 语言列表里显示成什么。**写成它自己的语言** —— 中文写"简体中文"，英文写"English"。这一项不翻译，翻成 "Chinese" 反而让人认不出来。 |
| `system` | 这个语言对应 Windows 的哪些语言名。选"跟随系统"时就是拿系统的语言名来这儿对。 |

`strings` 就是键名到译文。**键名一个都不能改**，改了就找不到了。

## 文件名

文件名就是语言代码（`zh_CN.json` → `zh_CN`），它也是写进 `MediaCast.json` 里
`ui.language` 的那个值 —— 用户打开配置文件和这个目录能直接对上。

**格式要求只有一条：只能用英文字母和下划线。** 别的随便。

## 基准语言是英文

`en_US.json` 是**基准语言**：它跟着 exe 一起编进去一份。某个键在别的语言文件里
漏了、或者整个 `lang` 目录被删了，界面就用它兜底，所以最坏情况是英文，不会是
一堆 `ui_settings_language` 这样的键名。

磁盘上如果有 `en_US.json`，以磁盘上那份为准（改英文的错别字不用重新编译）。

## `system` 那一项怎么填

往里写 Windows 的说法，中划线换下划线（`zh-Hans-CN` 写成 `zh_Hans_CN`）——
两种写法程序都认。选"跟随系统"时，程序拿系统的语言清单从上往下找，**第一个
对上的**就用它。

对不上会怎样：这个语言在"跟随系统"下永远不会被自动选中，**但它照样出现在
语言列表里**，用户可以手动选。所以这一项不用求全，漏写了只是自动选不中。

一个语言文件都没对上，就用基准语言（英文）。

## 加一种语言

1. 复制一份 `en_US.json`，改名成语言代码（比如 `ja_JP.json`）
2. 改 `meta.name`（写成 `日本語`）和 `meta.system`（填 `ja_JP` 之类）
3. 把 `strings` 里每一条的译文填上
4. 存进 `lang/`，重新打开程序 —— 列表里就有了

不用重新编译，不用碰代码。

## 键名怎么起

小写字母加下划线，用第一段表示这东西在哪儿：

| 前缀 | 用在哪 |
|---|---|
| `media_` | **内容本身的说法**（类型名、来源、未知这类），界面和 Windows 媒体面板共用 |
| `ui_` | 新界面（QML）：顶栏、控制栏、设置页…… |
| `tray_` | 托盘菜单 |
| `panel_` | Windows 那个音量面板（媒体控制） |

后面按"位置_东西"接着写，比如 `ui_settings_language`、`tray_open_main`。

## 文案怎么写

**中文和拉丁字母、数字之间留一个半角空格。** 这是中英混排的通行写法，
不留空格读起来会挤在一起：

```
对：支持 DLNA 的应用均可使用，例如系统相册、BubbleUPnP 等
错：支持DLNA的应用均可使用，例如系统相册、BubbleUPnP等
```

反过来，中文和**全角标点**之间不留空格（`，「」（）` 紧挨着字）。

**标点不混用：** 中文句子用全角（`，。、：`），英文句子用半角（`, . :`）。
同一句里别一半全角一半半角。

**用书面语，但别端着。** 面向的是普通用户：把"会发生什么"说清楚，比客气话
有用。同一个意思，选短的那个——

```
好：关闭窗口将结束本次投送，手机端也会断开连接。
差：如果您关闭本窗口，那么本次投送将会被终止，手机端亦将断开连接。
```

**按钮和状态标签保持短。** 它们不是句子，不用凑成完整的一句话：
`播放`、`断开连接`、`未连接` 这样最好。

**同一个东西在哪儿都叫同一个名字。** 一个词只指一件事，别一处叫"投屏"、
另一处叫"投射"——用户会以为是两个功能。

这条有两个**故意的例外**，都是为了让人找得到、看得懂：

1. **引用手机上的按钮名时**，跟着手机的说法写（手机上就叫"投屏"「投射」）。
   这不是我们自己的词，改了反而对不上。
2. **第一次引导用户的地方**，该出现"投屏"就出现一次——用户脑子里的词是它。

我们自己的状态、操作和设置项统一用**"投送"**（更书面，也和日志、配置项
`cast.newcast` 对得上）。所以规则是：**说"我们要干什么"时用"投送"，说
"用户会怎么找我们"时可以出现"投屏"。**

## 几条规矩

**日志不翻译。** 日志是排查问题用的诊断通道，只翻其中一部分，得到的是"一半
英文一半中文"的日志流，更难看。要翻就整条通道一起翻，那是另一件事。

**界面文字走 `tr()` / `qsTr()`，参数用 Qt 那套 `%1`。** 比如
`"%1 second(s)"`，英文里先这么凑合，不去处理单复数。

**缺的键会落回英文基准，多的键会被忽略**，两种情况程序都会在自己的日志里
说一声（键名拼错了最容易在这儿露出来）。

**改完不用重启也能生效**：设置页里切一下语言，或者重启程序。
