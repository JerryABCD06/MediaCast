# 行为矩阵

基线：`6c990a3`

本文记录旧 QML UI 的现行行为和 Avalonia 必须保持的行为。矩阵中的“定义”
表示迁移契约，不表示新 UI 已经完成。没有真实交互证据的项目只能标记为
“待验收”。

## 1. 事实与展示状态

只读事实只能来自以下所有者：

| 事实 | 所有者 | UI 消费形式 |
|---|---|---|
| `peerConnected`、当前 owner、投送会话 | Protocol | `PlaybackProjection` |
| 当前媒体、下一条、上一条可用性 | Protocol | `PlaybackProjection` |
| 逻辑 transport 状态 | Protocol，由 UI 播放事实驱动 | `PlaybackProjection` |
| 实际加载、播放、暂停、停止 | PlaybackController | `PlaybackProjection` |
| position、duration、media size | MPV | `PlaybackProjection` |
| volume、mute | MPV | `PlaybackProjection` |
| 轨道、容器、编码、实际媒体类型 | MPV | `MediaInfoProjection` |
| 语言、主题、强调色、Mica、持久设置 | Shell | `ShellProjection` |
| 页面、overlay、焦点、输入模式 | Avalonia | UI 本地状态 |
| 窗口普通/最大化/全屏事实 | Avalonia 窗口层 | UI 本地窗口状态 |
| 正在拖动时的临时 slider 值 | Avalonia 手势层 | 手势结束即失效 |

Avalonia 可以保存最近一次快照作为不可变只读投影，但不得把该缓存升级为第二
权威，也不得用本地布尔值替代 `peerConnected`、播放状态或命令完成结果。

## 2. 投送页状态

| ID | 状态 | 前置事实 | UI 显示 | 允许动作 | 禁止动作 |
|---|---|---|---|---|---|
| C-01 | 未连接 | `peerConnected=false`，`NoMedia` | 投屏引导、未连接状态 | 设置、信息、画面设置 | 推断“投送已结束”的完成时点 |
| C-02 | 已连接但无媒体 | `peerConnected=true`，`NoMedia` | 已连接状态和投屏引导 | 打开设置、信息、断开 | UI 自行创建媒体 |
| C-03 | Preparing | `Preparing` | 保留播放表面，显示准备状态 | 播放/暂停、停止、断开 | 因尚未出帧而销毁 renderer |
| C-04 | Playing 视频 | `Playing`，`kind=Video` | 视频画面，按规则显隐控制栏 | 播放暂停、Seek、音量、菜单、全屏 | 切页或布局时移除视频 host |
| C-05 | Playing 音频 | `Playing`，`kind=Audio` | 元数据和空画面底，控制栏常显 | 播放暂停、Seek、音量、菜单 | 为“无视频”销毁播放器 |
| C-06 | Playing 图片 | `Playing`，`kind=Image` | 图片画面，静止画面控制栏规则 | 播放暂停、Seek、音量、全屏 | 把图片序列当成无媒体 |
| C-07 | Paused | `Paused` | 保持当前帧和元数据 | 播放、Seek、音量、全屏 | UI 直接改 `paused` 权威 |
| C-08 | Stopped | `Stopped` | 保留已连接状态，可重新播放 | 播放、Seek、断开 | 用“卸载媒体”实现 Stop |
| C-09 | 自然结束且有下一条 | Playback 报告结束，`hasNext=true` | 由播放状态机推进 | 等待 Playback 的下一状态 | UI 自己调用 Next |
| C-10 | 自然结束且无下一条 | `Stopped`，无 next | 显示可重新播放状态 | 播放、断开 | 清空 Protocol 的媒体记录 |
| C-11 | 加载失败 | `Stopped`，`loadStatus=Failed` | 稳定失败状态，可重新投送 | 重投、断开 | 无限重试或伪装成功 |
| C-12 | 正在断开 | Protocol 正在处理 EndSession | 避免重复断开 | 等待核心状态更新 | UI 先清空媒体并宣称断开完成 |
| C-13 | 投送结束 | `NoMedia`，`peerConnected=false` | 回到未连接页 | 等待下一次投送 | 保留上一条为可播放内容 |

`Preparing`、`Playing`、`Paused` 都属于“当前有内容”，不能因画面暂时没有新帧就把
媒体状态降为 `NoMedia`。

## 3. 播放命令

| ID | 事件 | 唯一入口 | 命令语义 | 完成判据 |
|---|---|---|---|---|
| P-01 | 播放/暂停按钮 | UI semantic action | `TogglePlayPause` | 从后续 PlaybackProjection 观察 |
| P-02 | 画面单击 | 统一指针仲裁器 | `TogglePlayPause` | 同上 |
| P-03 | 上一首 | UI semantic action | `Previous` | `hasPrevious` 和能力结果 |
| P-04 | 下一首 | UI semantic action | `Next` | `hasNext` 和能力结果 |
| P-05 | 进度点击 | 进度条手势所有者 | 松手提交一次绝对 `Seek` | 后续 position 快照 |
| P-06 | 进度拖动 | 同一手势所有者 | 拖动只更新本地 preview，松手提交最终值 | 不能因快照更新回弹 |
| P-07 | 音量点击/拖动 | 音量控件单一所有者 | 拖动中实时下发 volume；松手补交最终值 | MPV 回传 volume |
| P-08 | 静音 | 单一 semantic action | `SetMuted(!muted)` | MPV 回传 mute |
| P-09 | 画面调节滑动 | 画面设置单一所有者 | 拖动中实时下发对应值；松手补交最终值 | MPV 回传 picture 值 |
| P-10 | 画面复位 | 单一按钮 | `ResetPictureControls` | 全部值回到 neutral |
| P-11 | 断开投送 | 顶栏/关窗确认 | `UiEndCastRequest` | Protocol 的会话事实更新 |
| P-12 | 字幕 | 尚未实现 | 明确禁用占位 | 不得伪装为已完成 |

UI 不直接构造 `PlaybackCommand`，不直接调用 `mpv_command` 或
`mpv_set_property`。所有语义命令进入 native UI host 内的既有
PlaybackController/PlaybackBridge 路径。

### 3.1 Seek 与音量不是同一种手势

```text
Seek:
  PointerPressed -> 捕获手势，更新 preview
  PointerMoved   -> 只更新 preview
  PointerReleased -> 提交最终绝对位置
  CaptureLost/失去焦点/取消 -> 恢复到最近权威 position

Volume / Picture:
  PointerPressed -> 捕获手势，预先广播 BeginControlAdjustment
  PointerMoved   -> 实时把当前值送入播放核心
  PointerReleased -> 再次提交最终值，广播 EndControlAdjustment
  CaptureLost/失去焦点/取消 -> 提交最后有效值后结束手势
```

拖动过程中，高频播放事实仍由播放核心更新；UI 只允许不打断当前手势投影。
松手后必须立即回到权威快照。

## 4. 媒体栏显隐

| ID | 条件 | 期望 |
|---|---|---|
| B-01 | `!showsPicture` | 控制栏常显 |
| B-02 | 视频 Playing，指针进入下沿热区 | 显示;离开栏和热区后收起 |
| B-03 | 视频 Paused、图片、其他静止画面 | 指针在画面内移动后显示，数秒后收起 |
| B-04 | 新视频开始 | 首次显示后短时强制显示 |
| B-05 | 指针位于控制栏 | 不收起 |
| B-06 | 菜单、音量浮层、信息浮层打开 | 不收起 |
| B-07 | 菜单或浮层关闭 | 重新按当前输入模式计时 |
| B-08 | 动画开关关闭 | 所有显隐直接落终态 |

所有计时器必须属于同一媒体栏显隐状态机。页面、按钮和 overlay 不得各自维护
一套“鼠标刚离开”的计时。

## 5. 菜单、信息和焦点

| ID | 事件 | 前置 | 行为 | 收尾 |
|---|---|---|---|---|
| O-01 | 画面右键 | Cast 页、无 overlay | 打开媒体菜单 | 退出时不透传到画面 |
| O-02 | Menu 键 | 媒体焦点 | 打开同一媒体菜单 | 恢复媒体焦点 |
| O-03 | Shift+F10 | 媒体焦点 | 打开同一媒体菜单 | 恢复媒体焦点 |
| O-04 | Esc | 任一 overlay 打开 | 调唯一 CloseOverlay | 恢复进入前焦点 |
| O-05 | 点击外部 | overlay 打开 | light dismiss | 该点击不得触发播放或全屏 |
| O-06 | 信息按钮 | 信息已打开 | 关闭信息 | 焦点回信息入口 |
| O-07 | Tab | overlay 内 | 焦点留在 overlay | 关闭后恢复 |
| O-08 | 打开设置 | 非全屏 | 进入 Settings route | Cast 事实和播放表面保持存活 |
| O-09 | 设置返回 | Settings | 回到 Cast | 焦点回到进入前入口 |
| O-10 | 全屏期间 Esc | 无 overlay | 退出全屏 | 恢复全屏前窗口状态 |

右键、键盘菜单键和 Shift+F10 只能进入同一个菜单组件和同一个
`OpenOverlay(MediaMenu)` 状态转换。

## 6. 窗口与渲染生命周期

| ID | 场景 | 必须保持 | 必须验证 |
|---|---|---|---|
| W-01 | 首次打开主窗口 | 播放器、render context、surface 各只有一个 | `UiFirstFrame` 只上报一次 |
| W-02 | Cast -> Settings -> Cast | 视频 host 和 render context 不销毁 | 返回后画面不黑、不重载 |
| W-03 | 普通 -> 最大化 | 媒体、position、context 保持 | surface 跟随客户区尺寸 |
| W-04 | 普通/最大化 -> 全屏 -> 退出 | 原窗口 placement 恢复 | Avalonia 标准窗口能力优先 |
| W-05 | 全屏 -> Esc | 无 overlay 时退出全屏 | 有 overlay 时先关闭 overlay |
| W-06 | 全屏 -> 最小化 -> 恢复 | 不销毁 render context | 恢复后继续出帧 |
| W-07 | resize | 只改变 viewport/FBO 尺寸 | 不重建 render context |
| W-08 | 移动窗口 | 可以暂停画面呈现以保持拖动流畅 | 不停止播放、不卸载媒体 |
| W-09 | 跨显示器/DPI | 使用当前 TopLevel scaling | 不按旧 DPI 固定 viewport |
| W-10 | 无投送关窗 | 直接退出窗口 | 不弹无意义确认 |
| W-11 | 有投送关窗 | 显示关闭策略 | 不能静默丢投送 |
| W-12 | 关闭并断开 | 先同步必要状态再退出 | 命令必须有超时 |
| W-13 | OpenGL context lost | 失败关闭并记录 | 不伪造成功、不创建第二个 renderer |

QML 为了规避 Qt OpenGL 全屏丢表面而实现的 HWND/overscan/二次几何同步规则，
不能直接移植。Avalonia 窗口状态优先使用框架标准能力；只有真实复现框架缺陷时
才单独立项平台补丁。

## 7. UI 路由与页面契约

```text
Route
  Cast
  Settings

Overlay
  None
  Info
  MediaMenu

InputMode
  Mouse
  Keyboard
  Touch
```

约束：

- Settings 只能在非全屏进入;
- 全屏只允许 Cast route;
- 同一时刻只有一个 overlay;
- overlay 打开时记录进入前焦点，关闭后恢复;
- 设置页不得覆盖或销毁 Cast 页的视频 surface;
- 非活动页不进入可访问性树，也不接收输入。

设置页优先使用 Avalonia/Fluent 提供的标准 `NavigationView`、`SplitView`、
设置卡片和 ToggleSwitch 语义，不照搬 QML 的自绘侧栏结构。

## 8. 可访问性

每个交互元素必须有：

| 元素 | 名称 | 角色/模式 | 键盘 |
|---|---|---|---|
| 播放/暂停 | 当前动作名 | Button/Invoke | Enter、Space |
| Seek | 媒体进度 | Slider/RangeValue | 方向键 |
| Volume | 音量 | Slider/RangeValue | 方向键 |
| Mute | 静音/取消静音 | Toggle/Check | Enter、Space |
| 设置导航 | 页面名称 | Navigation/List item | 方向键、Enter |
| Toggle | 设置名称 | ToggleSwitch/Toggle | Space |
| 菜单 | 可读菜单项 | Menu/MenuItem | 方向键、Esc |
| 信息 | 标签和值 | 可读分组 | Tab 受限 |

状态变化只通知有意义的变化，不能每帧更新讲述人。

## 9. 真实交互验收

以下项目没有真实操作证据时不得写“已修复”：

- 鼠标左键单击、双击、右键;
- Shift+F10、Menu 键、Tab、Esc、Enter、Space;
- 菜单打开时点击底层画面不透传;
- Seek、音量、画面调节拖动、取消、失焦和 PointerCaptureLost;
- 设置页往返后视频不黑屏;
- 真实拖边 resize、最大化、全屏、最小化恢复;
- 多显示器和混合 DPI;
- UIA 树、键盘焦点和讲述人;
- 首帧、准备、暂停、恢复、停止、自然结束、再次投送。

## 10. 明确排除

本次迁移不阻塞于：

- 纯 UI 本地化和全文文案替换;
- 完整媒体栏;
- About / Legal / Licenses 页面;
- 旧 Qt/QML/FluentUI 的删除和兼容;
- 字幕选择功能;
- QML 专用视觉细节。

这些项目不得被用来绕过核心状态、命令顺序和渲染生命周期验收。
