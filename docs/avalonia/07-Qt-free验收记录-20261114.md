## 5. 已修复的故障路径

### PlaybackPipe 重连

真实故障注入已通过：

```text
PlaybackPipe disconnected
Playback UI ready
PlaybackPipe reconnected
Ui playback reconnect completed
```

修复保持 Ui PID、窗口、MpvCore 和 render context 不变；详见
[05-核心提案-PlaybackPipe重连释放旧实例.md](05-核心提案-PlaybackPipe重连释放旧实例.md)。

### ControlPipe 断管

`mcast_control_pipe_fail_closed` 真实断开 ControlPipe，断言 Ui 在 12 秒内退出。

### OpenGL renderer 故障

`mcast_opengl_context_lost_fail_closed` 注入 render context 丢失，Ui 发布
`contextLost=true` 并失败关闭。

### confirmation-only 自动冷启动

轻量 confirmation-only Ui 已通过自动烟测，不创建 MPV、PlaybackBridge、SMTC 或
render context。Shell 自动冷启动仍受冻结边界限制。

见
[06-核心提案-confirmation-only冷启动.md](06-核心提案-confirmation-only冷启动.md)。
