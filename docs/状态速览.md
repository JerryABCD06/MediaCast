# 状态速览

> 本页只做入口。现行事实的完整说明见 [当前实现总览.md](当前实现总览.md)。

- 生产入口：`MCast.Shell.exe` + `MCast.Protocol.exe` + `MCast.Ui.exe`。
- Shell 常驻，Protocol 常驻，Qt/QML/MPV UI 只在窗口需要时存在。
- 当前协议：DLNA / UPnP AV；视频、音频、图片和兼容 HLS 路线已可用。
- 当前主功能缺口：字幕。
- 当前进程监督缺口：Protocol 自动重启、Shell 反向拉起和 confirmation-only
  自动冷启动尚未接入。
- 当前发布缺口：没有正式 `install()`、CPack、Qt 部署和发布清单入口。
- 当前 CTest 注册数：40。通过率必须带日期和构建目录，不能从注册数推断。
