**启动时不弹窗口**，只在托盘里待着；有东西投过来（或者托盘菜单点「打开主界面」）
才开窗口。（旧的 Qt Widgets 界面 2026-09-14 退场了。）

## 怎么构建、怎么跑

- 构建：`work\build-mcast.ps1`（增量）；改了 CMake 或 `.h` 用
  `work\configure-mcast.ps1 -Build`（重配 + 全编）。
- 跑：exe 旁边没有 Qt DLL，**双击会弹缺 `Qt6Widgetsd.dll` 之类的框**。得先把它
  加进 PATH：`$env:PATH = 'D:\Apps\Qt\6.11.2\msvc2022_64\bin;' + $env:PATH`，
  然后 `Start-Process -FilePath '...\mcast-build11\MCast.exe' -WorkingDirectory '...\mcast-build11'`。
- 发布：`work\configure-mcast-release.ps1 -Build`（编 Release）→
  `work\deploy-mcast.ps1`（windeployqt 补齐 + 整份拷到桌面）。细节在 `待办.md`。
- 注意：`Start-Process` 加 `-RedirectStandardError` 起的进程会被回收掉 —— 要收
  stderr 就**在同一条命令里**起、跑完、再读文件。

## 分层

```
DLNA（protocols/dlna/）   ← 只管 UPnP/SOAP，不碰播放器
    ↓ 中性枚举
PlaybackController（core/）  ← 状态的唯一来源
    ↓
MediaPlayer（core/MediaPlayer.h，抽象接口）
    └── MpvCore              mpv 实例 + 事件线程 + 状态缓存 + 命令 + 画面调节
          ├── LibMpvPlayer   wid 外壳（**现在没人用**，留着当退路）
          └── MpvQmlItem     render API 外壳（在用的就是它，画面进 QML）

UI：ui/NewUiWindow.* + ui/qml/**（唯一那套界面）
    界面只读 PlaybackController 的状态，不自己拼
    Windows 媒体面板挂在**一个常驻的隐藏窗口**上（不挂主界面那扇 —— 它关了会真销毁）
```

## 状态只有一份（界面照着读，别自己拼）

界面上会问的"局面"其实就两条，都算在 `PlaybackController` 里：

| 问什么 | 读哪个 | 谁在算 |
|---|---|---|
| 手机连着没有 | `Playback.peerConnected` | 协议层喂（有 GENA 订阅、且不是我们主动挂断） |
| 在投送视频 / 音乐 / 图片，还是没在投 | `Playback.castState` | `peerConnected` × 内容类型 × `idle`，就那十来行 |

消费方：顶栏状态胶囊和「断开连接」按钮、投屏页的引导语、关窗确认框 —— **全读这两条**，
一处组合判断都没有。`2026-09-14` 逐个数过一遍，只有 `castState()` 里一句注释过期
（写着关窗看 `hasMedia`，其实早就换成 `peerConnected` 了），已经改掉。

更细的那几个量（`showsPicture` / `mediaIsVideo` / `paused` / `hasMedia` / `idle`）
是**别的问题**用的（屏幕上有没有画面、控制栏该用哪套颜色、点一下有没有意义），
各自在头文件的注释里写明了为什么不能用上面那两条替代 —— 别混。

## 会咬人的约束

1. **改过任何 `.h`，必须删掉整个构建目录重配重编**。增量构建会漏依赖，
   结果是编译链接全过、一跑就崩。
2. PowerShell 长命令会被策略拦；`Remove-Item` 被挡。**写 `.ps1` 再跑**，删文件用
   `[System.IO.File]::Delete` / `[System.IO.Directory]::Delete`。
3. 提交信息**写进 `work\commitmsg.txt` 再 `git commit -F`**（长 `-m` 会被编码搞坏）。
4. **QML 里切页不能把 `MpvQmlItem` 藏起来**（render API 靠每帧渲染推进）；
   要"藏"就缩成 1×1。
5. 开关、滑块**别用 `checked: X.y` / `value: X.z` 绑属性**，一点就断。
6. 新加的 QML 文件要同时写进 `res/QmlUi.qrc`，改完要确认 rcc 真的重编了。

## 界面上的几个时间常数

| 值 | 用在哪 |
|---|---|
| 167 ms | 控制栏显隐动画（Fluent 库自己的标准） |
| 3 s | 暂停 / 图片时鼠标停手后收起 |
| 5 s | 新投上来的视频先露一会儿 |
| 250 ms | 画面单击（播放/暂停）延迟执行，等双击 |

## 下一步

控制栏右侧那排键里，**全屏**、**音量**、**显示效果**都已经是真的（音量滑块是
自己画的；显示效果是个独立窗口，十来条滑块从后端那张表长出来 —— 理由都在各自

`Playback.hasNext` / `hasPrevious`。**大多数时候它们就是灰的** —— 那是如实
显示：控制点普遍不排下一条、也不按上一首（见 `DLNA实现情况.md`）。
