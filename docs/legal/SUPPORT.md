# Media Cast — Support

Media Cast is an open-source project maintained on a best-effort basis.

## Bug Reports

Please provide:

- Media Cast version;
- Windows version;
- protocol being used;
- sender application and version;
- steps to reproduce;
- relevant logs or error messages.

## Feature Requests

Explain the use case rather than only requesting a specific implementation.

For protocol support, identify the sender or receiver that should interoperate with Media Cast when possible.

## Compatibility

Compatibility with one device or application does not guarantee compatibility with every implementation of the same protocol.

Protocol behavior may vary between vendors and versions.

## Security Issues

Do not use public issues for undisclosed security vulnerabilities. Follow `SECURITY.md`.
