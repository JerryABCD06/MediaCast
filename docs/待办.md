## 一、等您拍板的一件事（挡住后面）

**画面放哪边。** `main.cpp` 里一个常量：

```cpp
constexpr bool kRenderVideoInNewUi = false;   // 约 133 行
```

一个 mpv 实例**只能有一条画面输出路径**（`vo` 只能设一次，wid 和 render API
互斥），所以画面只可能出现在其中一边：

| 取值 | 画面在 | 代价 |
|---|---|---|
| `false`（现在） | 旧界面 | —— 现有行为不变 |
| `true` | 新界面 | **旧界面的画面区会变空** |

DLNA 那一层两条路都不受影响。这条不定下来，"新界面变成真正能用的播放界面"
那一步就没法往下走（做出来的东西没画面可看）。

## 二、下一段主体工作

### 1. 抽 PlaybackController

早就说好的第二阶段。现在 DLNA 是直接调 `MediaPlayer` 的；将来要多协议
（AirPlay 之类）时，每个协议都去写一遍"播放/暂停/进度/队列"的状态机是不行的。

目标形状：

```
DLNA ──┐
AirPlay┤
Cast ──┤ ──▶ PlaybackController ──▶ MediaPlayer ──▶ libmpv
       ┘
```

协议层只剩"翻译"和"用本协议的话报状态"。

### 2. 新界面做成真正的播放界面

现在新界面上的按钮**全是死的**。要接：

- 打开文件 / 播放 / 暂停 / 停止
- 进度条（拖动 → seek）
- 音量
- 队列（上一首 / 下一首）

有了 PlaybackController 之后这些会简单得多 —— 界面只跟它说话。

### 3. 旧界面退场

新界面能用了之后：

- 托盘菜单里的「打开主界面」改成开新界面
- 启动时不再弹旧窗口
- 删掉 `ui/MainWindow.*`、`ui/qml/TopNav.qml`，以及 `kRenderVideoInNewUi`
  这个过渡开关（那时只剩一条路）

**别提前删。** 旧界面现在还是唯一能看到画面的地方，也是 DLNA 回归测试的
观测窗口。

## 三、已知故障

### Qt Creator 一打开这个工程就卡死

**症状**：Qt Creator 启动后主窗口立刻无响应（Windows 判定 `IsHungAppWindow`），
一直吃满一个核。实测盯了 30 分钟没恢复：

```
样本  1   CPU累计   502.0s  内存 609MB  响应=False
样本 90   CPU累计 2,178.5s  内存  42MB  响应=False
```

内存一路从 609MB 降到 42MB —— 它在死循环里把东西都释放了，但出不来。

**已排除**：不是编译慢（编译时根本没有编译器在跑，而且命令行构建 94 秒就完）、
不是内存不够（内存一直在降）、不是构建输出太多。

**怀疑对象**：给工程加进 FluentUI（180 个源文件，含 1.3 MB 的
`qcustomplot.cpp`、662 KB 的 `Chart.js`）之后才出现的。

**下一步验证**（30 秒，不用编译）：把 `CMakeLists.txt` 里的
`add_subdirectory(third_party/FluentUI ...)` 暂时注释掉，重新配置，打开工程——
如果 Qt Creator 不卡了，怀疑成立。

**不挡路**：命令行能编能跑，只是每次都得把 Qt Creator 杀掉比较烦。

## 四、搁置的小事

按"想起来再做"排序，都不紧急：

- **新界面的「播放器未就绪」占位文字**：条件写成了 `!Player.running`，
  而 `running` 是"引擎起来了没有"——引擎开机就在跑，所以这行字永远不显示。
  想要"没东西在播"的提示得换个条件。用户说无所谓。
- **顶栏样式**：现役是 `FluPivot`，观感偏 Windows 10（下划线只跟文字一样宽、
  字号是标题级）。要 Win11 的样子得用我们自己写的 `TopNav.qml`（支持图标、
  支持左右分列）—— 它现在是**停用**状态，没进 `.qrc`，文件头和 `.qrc` 的
  注释里写了怎么启用。
- **「上一首/下一首」的定位**：详见 `DLNA实现情况.md` 的"待定/待测"。
  三个候选做法，还没定。
- **用户设置文件**：现在日志写在 exe 旁边。计划挪到
  `%LOCALAPPDATA%\MediaCast\`（config / renderer / logs / cache）。
- **发布目录整理**：`windeployqt`、把 libmpv 放进 `runtime/mpv/`、
  新界面要带的 QML 模块。
- **媒体面板的程序名和图标**：试过 AUMID 没成，线索是要加开始菜单快捷方式。
- **AVTransport:2 的 `SetStateVariable` / `GetStateVariable`**：
  DLNA 唯一还欠的协议项。
- **构建慢**：FluentUI 的 `qmlcustomplot` 已经剔掉了（见
  `third_party/PATCHES.md`），第一次构建 94 秒。要是还嫌慢，可以把
  Qt Creator 的并行数降到 6。
