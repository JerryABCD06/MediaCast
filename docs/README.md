# 文档索引

本文档目录把“现行事实”“操作手册”“真机观察”和“历史快照”分开。发生冲突时，
优先级是：

1. 当前源码、测试和可复现日志；
2. 本目录中的现行规范；
3. `docs/history/` 中的历史记录。

历史文档用于解释“为什么变成今天这样”，不能作为当前实现依据。

## 历史目录

[history/README.md](history/README.md) 列出已冻结的重构交接、迁移阶段、九月 DLNA
实现、旧待办和旧文案表。历史条目仍可引用，但新增或修改实现说明必须写进现行
文档。

## 文档维护规则

- “目标设计”和“当前实现”必须分栏或分节，不能混写。
- 测试数量、提交号和工作树状态必须带日期；当前配置数量不能代替测试通过结论。
- 一次真机观察必须记录设备、应用版本、日期和证据文件，并标明是单次观察、
  多次复现还是代码已印证。
- 旧单进程入口、旧 Qt Widgets UI、旧 `mcast-build11` 构建目录和旧测试数字只留在
  历史文档。
- 跨文档只维护一份权威说明；其他文档用链接引用，不复制同一张状态表。
