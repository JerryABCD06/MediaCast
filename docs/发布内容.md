# 发布内容边界

更新日期：2026-11-12

生产三进程版本只收集：

```text
MCast.Shell.exe
MCast.Protocol.exe
MCast.Ui.exe
config/metadata-pipeline.json
lang/
qml/
legal/
licenses/
```

以及 Qt、libmpv 和其他运行时依赖。

仓库不再构建 `MCast.exe`；发布入口只有上述三个进程。

`lang/` 必须完整保留目录结构，不能把各语言的 `ui.json` 重新摊平到
`lang/*.json`。

`config/metadata-pipeline.json` 也必须随包发布。缺失时程序会用内置默认值继续
运行，但用户就无法通过数据文件调整标题、作者、专辑和副标题的过滤规则。

当前只有“应包含什么”的边界，没有正式安装器或一键打包入口。构建、部署依赖、
发布闸门见 [构建测试与发布.md](构建测试与发布.md)。
